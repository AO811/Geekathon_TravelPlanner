# Travel Planner Website

A dynamic and responsive website designed to streamline travel planning, developed during the Geekathon Hackathon using only HTML, CSS, and JavaScript.

### Project Overview:
The Travel Planner Website offers an intuitive platform for users to explore travel-related services and connect with support teams, providing a seamless experience for planning trips and vacations.

### Key Features:
- Home: A visually engaging landing page showcasing the website’s purpose and services.
- Services: Detailed information on travel packages, itineraries, and other offerings.
- About Us: Insight into the team and mission behind the project.
- Contact Us: Easy-to-use forms for inquiries and direct communication.
- Help & Feedback: A dedicated section for user assistance and collecting feedback for continuous improvement.

### Technologies Used:
- HTML: For structuring web content.
- CSS: For creating a responsive and appealing design.
- JavaScript: For adding interactivity and enhancing the user experience.

This project highlights creative problem-solving and front-end development skills under a time-constrained hackathon environment.
